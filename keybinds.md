# Keybinds
All the keybinds (and commands) that are available and useful

Keybinds:
- `<leader>gv`: Rename variable
- `gpd`: Preview Definition
- `gpt`: Preview Type Definition
- `gpi`: Preview Implementation
- `gcc`: In Normal, comment current line
- `gc`: In Visual, comment current line
- `<leader>fg`: Telescope Live Grep
- `<leader>ff`: Telescope Find Files
- `grf`: In Normal mode, format current file
- `<leader>ca`: Trigger code action
- `<leader>xx`: View all diagnostics

Commands:

- `:OpenTerm`: Opens a terminal
- `:DiffOrig`: Difference between your edits and the original
